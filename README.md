Fixed-Amount QR Payment Tracker

About

This is a Java-based college project for tracking fixed-amount QR payment transactions in demo mode.

Main Features

- Fixed payment amount validation
- Simulated payment statuses
- Transaction ID and duplicate checking
- SQLite database storage
- Payment history and collection summary
- Search and CSV export

Team Roles

- Member 1: User Interface
- Member 2: Payment Logic
- Member 3: Database and Reports
- Member 4: Integration and Testing

Important Note

This project uses simulated transactions for demonstration. It does not verify real bank or UPI payments.
